# Roxel Parkour — GLB Animations

Coloque nesta pasta os arquivos `.glb` que contêm animações do personagem, incluindo animações de morte, flips e outras ações.

Objetivo: identificar os nomes das animações e os esqueletos/ossos correspondentes para reproduzir as animações no personagem dentro do Godot, sem deslocar o personagem pelo movimento gravado no arquivo.

Observação: a animação visual será separada do movimento físico do personagem. Para isso, as transformações de deslocamento do nó raiz precisam ser ignoradas ou removidas quando apropriado, mantendo as rotações e movimentos dos ossos.
