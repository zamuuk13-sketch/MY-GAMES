# TERROR NIGHT

Jogo de terror 3D para PC feito em Godot 4.

## Objetivo
1. Encontre os 3 fusíveis.
2. Encontre a chave enferrujada.
3. Vá até o gerador e ative-o.
4. Quando a criatura acordar, corra para a porta de saída.
5. Interaja com a porta para escapar.

## Controles
- WASD: mover
- Mouse: olhar
- Shift: correr
- F: ligar/desligar lanterna
- E: interagir
- F5: reiniciar

## Estrutura
Este jogo fica isolado em `TERROR_NIGHT/` para que o repositório MY-GAMES possa receber vários jogos independentes no futuro.

O protótipo não depende de assets externos: cenário, itens, iluminação e criatura são criados por código para facilitar o primeiro teste no PC.
