# Spider City

Third-person Spider-Man-inspired traversal prototype for Godot 4.

## Current build
- Daytime procedural city with many buildings.
- Third-person camera.
- Procedural masked spider-hero character.
- WASD movement and sprint.
- Jump impulse scales with running speed.
- Wall detection and climbing.
- Falling/dive pose when airborne and looking downward.
- Configured web anchor points placed on buildings.
- Hold E to web swing from the best visible/facing anchor.
- Pendulum-like rope constraint and momentum.
- Space during a swing releases with an upward/forward impulse.
- Procedural traversal animations for idle, run, sprint, climb, swing and fall.
- Web rope visualization.

## Planned audio/asset pass
The prototype intentionally uses no external binary assets yet. The next pass can add licensed character/environment models, footsteps, wind/air-rush layers, web impact/release sounds, landing sounds and higher-quality animation clips.

## Controls
WASD = move
SHIFT = run
SPACE = jump / swing release
E = hold to web swing
Mouse = camera

The folder is isolated so MY-GAMES can contain many independent games.
