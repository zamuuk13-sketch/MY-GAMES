# AVIATOR

RPG de aviação 2D em Godot.

Fluxo inicial:
Escolha da nação -> Nível 1: Primeiro Combate -> batalha aérea -> recompensas -> hangar.

Nações:
- Estados Unidos
- Rússia

O projeto foi organizado de forma modular em dados de aeronaves, campanha, IA, combate, progressão, hangar e save. A primeira fase é implementada por completo; níveis 2-10 ficam preparados para expansão.

Controles:
- WASD: movimentação
- SHIFT: acelerar
- CTRL: desacelerar
- ESPAÇO: disparar
- E: arma especial
- ESC: sair da batalha/menu

O jogo usa arte 2D procedural para não depender de assets externos no protótipo. Sons e música possuem pontos de integração no código para a próxima camada de conteúdo.
