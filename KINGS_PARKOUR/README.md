# Kings Parkour

Protótipo inicial de um jogo de parkour 2D feito em Godot 4.

## Como jogar
- **A / D** ou **setas esquerda/direita**: correr.
- **Espaço**, **W** ou **seta para cima**: pular.
- Se cair, você volta ao início.
- Chegue à bandeira rosa para vencer.

## Abrir
Abra `project.godot` na pasta `KINGS_PARKOUR` usando o Godot 4.7 ou mais recente.

O cenário e o personagem deste protótipo são criados por código, então não precisa baixar assets para começar.
